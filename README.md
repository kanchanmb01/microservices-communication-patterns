# Microservices Communication Patterns

This repository demonstrates different service-to-service communication approaches in Spring Boot Microservices.

## Implementations

### 1. RestTemplate Prototype
- Eureka Discovery Server
- API Gateway
- Load Balancer
- Circuit Breaker
- RestTemplate Communication

### 2. Feign Client Prototype
- Eureka Discovery Server
- API Gateway
- OpenFeign
- Load Balancer
- Circuit Breaker

### 3. WebClient Prototype
- Reactive Communication
- Eureka Discovery Server
- API Gateway
- Load Balancer
- Circuit Breaker
